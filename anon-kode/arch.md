# ANON KODE 架构分析文档

## 项目概述

ANON KODE 是一个基于终端的AI编程助手工具，旨在为开发者提供智能的代码编写、调试和项目管理能力。该项目采用现代化的架构设计，支持多种AI模型，具有强大的扩展性和安全性。

### 核心特性
- 🤖 支持多种AI模型（Claude、OpenAI、Bedrock、Vertex AI）
- 🛠️ 丰富的内置工具集（文件操作、命令执行、代码搜索等）
- 🔌 MCP（Model Context Protocol）集成，支持第三方工具扩展
- 🔒 完善的权限管理和安全控制
- 💬 智能的终端交互界面
- 📝 会话历史和状态管理

## 技术架构

### 技术栈
- **前端框架**: React + Ink（终端UI）
- **开发语言**: TypeScript
- **AI集成**: Anthropic Claude SDK, OpenAI SDK
- **协议支持**: MCP (Model Context Protocol)
- **数据验证**: Zod
- **构建工具**: Bun
- **运行环境**: Node.js 18+

## 核心模块详解

### 1. 工具系统（Tools）

工具系统是ANON KODE的核心，采用插件化架构设计。

#### 工具接口设计
```typescript
interface Tool {
  name: string
  description?: string
  inputSchema: z.ZodObject<any>
  prompt: (options: { dangerouslySkipPermissions: boolean }) => Promise<string>
  isEnabled(): Promise<boolean>
  isReadOnly(): boolean
  needsPermissions(input: any): boolean
}
```

#### 内置工具
- **BashTool**: 执行Shell命令，支持超时控制和目录管理
- **FileReadTool**: 读取文件内容，支持图片和文本文件
- **FileEditTool**: 编辑文件，支持精确的字符串替换
- **FileWriteTool**: 创建新文件
- **GrepTool**: 使用ripgrep进行代码搜索
- **LSTool**: 列出目录内容
- **ArchitectTool**: 代码架构分析工具
- **ThinkTool**: AI思考过程记录
- **AgentTool**: 子代理调用

#### MCP工具集成
- 支持动态加载外部MCP工具
- 统一的工具接口适配
- 自动权限管理

### 2. 权限管理系统

#### 权限层级
1. **全局权限**: 跨项目的通用权限设置
2. **项目权限**: 特定项目的权限配置
3. **会话权限**: 当前会话的临时权限

#### 权限类型
- **文件系统权限**: 读取/写入文件的权限控制
- **命令执行权限**: Bash命令的细粒度权限管理
- **工具使用权限**: 特定工具的使用授权

#### 安全机制
- 危险操作需要用户确认
- 文件访问范围限制
- 命令执行沙箱
- Docker容器支持

### 3. MCP集成架构

#### MCP客户端
- 支持stdio和SSE两种传输协议
- 自动连接管理和错误恢复
- 工具和命令的动态发现

#### MCP服务器
- 将ANON KODE作为MCP服务器暴露
- 支持Claude Desktop等客户端接入
- 标准化的工具接口

#### 配置管理
- 支持全局和项目级MCP服务器配置
- 从Claude Desktop导入配置
- 服务器状态监控

### 4. 用户界面系统

#### REPL主界面
- 基于React + Ink的终端UI
- 实时消息渲染和状态更新
- 支持多种输入模式

#### 输入模式
- **普通模式**: 自然语言交互
- **Bash模式**: 直接执行命令（!前缀）
- **Koding模式**: 代码生成模式（#前缀）

#### 交互组件
- 智能命令补全
- 历史记录导航
- 工具使用确认对话框
- 成本和性能监控

### 5. 配置管理

#### 配置层次
```
全局配置 (~/.config/claude/config.json)
├── 用户偏好设置
├── AI模型配置
├── 主题和显示设置
└── 全局MCP服务器

项目配置 (项目根目录/.claude/config.json)
├── 项目特定设置
├── 工具权限配置
├── 项目MCP服务器
└── 上下文文件配置
```

#### 配置项
- AI模型选择和API密钥
- 详细模式和调试设置
- 权限和安全配置
- MCP服务器配置
- 主题和UI偏好

## 数据流架构

### 用户输入处理流程
```
用户输入 → 输入解析 → 命令/工具识别 → 权限检查 → 执行 → 结果渲染
```

### AI交互流程
```
用户消息 → 上下文构建 → AI模型调用 → 工具调用 → 结果整合 → 响应生成
```

### 工具执行流程
```
工具调用 → 参数验证 → 权限检查 → 实际执行 → 结果处理 → 状态更新
```
